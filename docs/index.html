02 · 模型观

Agent 即模型

不透传 function calling——ZCode 自主决定何时使用工具。你调用的是「能干活的 agent」，不是一堆等你编排的裸函数。

启动后看主界面账号卡：显示「已连接」即可直接使用；显示「未登录」就去 ZCode 桌面版登录一次——凭据库共享，代理自动跟上。

03

填三个字段

在任何支持自定义 OpenAI 接口的软件里，填上方的 API 地址、API Key 和模型名，保存后直接对话。

Python · openai SDK 
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8787/v1", api_key="anything")

r = client.chat.completions.create(
    model="zcode",
    messages=[{"role": "user", "content": "帮我在 D:/test 写一个天气爬虫"}],
    stream=True,
)
for chunk in r:
    print(chunk.choices[0].delta.content or "", end="")
先说清楚

它能干什么，不能干什么。

发布页不吹参数，这几条来自真实的已知边界与安全须知，装之前建议读完。

  • —每个请求新建引擎会话，首 token 延迟约 2–5 秒（引擎常驻，无进程冷启动）；agent 任务耗时较长，客户端超时建议 ≥ 5 分钟，代理侧默认 30 分钟。
  • —OpenAI 的 tools / function calling 参数不透传——工具调用由 ZCode 自主决定，客户端传了也不会生效。
  • —图片等多模态消息只取文本部分。
  • —与 ZCode 桌面版共享登录凭据与会话库，两者可同时使用、互不冲突；账号体系切换需重新登录（凭据按体系独立）。

它有真实的执行能力

默认 mode: yolo：ZCode 会自动执行工具（写文件、跑命令）。请保持只监听本机（默认如此），不要把端口暴露到局域网。

建议在 config.json 设置 apiKey，必要时用 disallowedTools 收紧可用工具。

mode: yolo host: 127.0.0.1 apiKey disallowedTools
常见问题

装之前，常被问到的几件事。

GitHub 下载慢或失败？+

用夸克网盘备用链接下载：pan.quark.cn/s/f2651ed7200e（提取码 zWxr）。GitHub 主链接始终指向最新版 Release。

前提是什么？一定要装 ZCode 桌面版吗？+

要。登录凭据与引擎都来自 ZCode 桌面版，应用会自动探测它的安装位置与数据目录，双击启动无需任何环境变量。

账号卡显示「未登录」或调用报 401 怎么办？+

在 ZCode 桌面版登录一次即可（凭据库共享，代理自动跟上），或点账号卡的「重新登录」按钮走授权流程。

报「余额 / 资源包不足」？+

该账号体系没有对应订阅。换另一个模型名试试——zcode（国际 Z.AI）与 zcode-bigmodel（国内 BigModel）的额度互相独立。

提示端口被占用？+

代理可能已经在运行：打开 http://127.0.0.1:8787/ 确认；确要改端口，编辑 config.json 的 port 后重启。
